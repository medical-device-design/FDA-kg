# Change log, 2026-10-14: link gaps closed, SHACL shapes and query battery, food inventories

## Link resolution now 100% (was 92 / 98 / 74%)
- `pipeline/l1_tables.py`: the warning-letter converter mints the name-keyed `RecallingFirm`
  node for every firm it links (2,611 firms), so warning letters and recalls meet on one node.
  warning_letters.ttl: 64,809 triples.
- `pipeline/l2_stubs.py` (new, first L2 step): scans a graph, finds every link target that no
  file declares, and writes a stub node (`ex:isStub true`, label, `ex:referencedBy` source files).
  fda-drug-biologic-kg/l2_stubs.ttl: 2,373 `DrugApplication` + 1,201 `NdcPackage` stubs,
  15,059 triples. Compliance needed none after the firm fix.
- Re-check: application 31,749 / 31,749, package NDC 81,180 / 81,180, firm 9,166 / 9,166.

## SHACL shapes (handoff requirement before any lakeFS upload)
- `pipeline/gen_shapes.py` generates `shapes/<graph>.shapes.ttl` (33 node shapes over six graphs)
  from one table: every top-level record has a label and a provenance block (stubs exempt),
  every cross-reference is an IRI in the owning graph's namespace, every date is xsd:date or
  the untouched source string, plus FDA value lists (recall classification, UNII pattern).
- Run with Jena `shacl validate` on the VM (`scripts/shapes_and_queries.sh`): tobacco,
  compliance and food-cosmetic whole; drug-biologic, substance and animal-health on slices of
  about 1.2 M node blocks (`pipeline/sample_ttl.py`). Result: all six conform, 0 violations.
- Two findings fixed on the way: FDA uses "Not Yet Classified" as a recall classification
  (4 recalls), and one recall carries two event ids; the Orange Book data-file exclusivity rows
  were typed `OrangeBookExclusivity`, the same name the openFDA child node gets, so the file
  rows are now `OrangeBookExclusivityRecord` (orangebook_files.ttl rebuilt, 1,340,528 triples).

## Query battery
- `queries/common_*.rq` (class counts, records per source and retrieval date) plus 22 per-graph
  queries in `queries/<graph>/`, run through TDB2 on the same data. Every query returns rows;
  highlights: 8,227 applications carry both openFDA and data-file provenance in the slice
  (29,376 whole); shortages reach their application through the shared package NDC node;
  CRLs join to sponsor labels; 3,108 recalls link to 856 substances; 465 King Bio recalls meet
  2 warning letters on one firm node; VeDDRA codes resolve with their names (vomiting 334,
  death 984). Full output in the VM logs `logs/shapes_and_queries_2026-10-14*.log`.
- Known data fact surfaced by q3: firm names vary between sources ("Dole Fresh Vegetables Inc"
  vs "Dole Fresh Vegetables, Inc."), so name-keyed firms split; FEI resolution stays an L2 item.

also given a `...Text` twin. CAS columns link to fda-substance-kg through a CAS -> substance map
