# Change log, 2026-10-27: phase 3 (the big openFDA sets, now that the 1 TB volume is in)

The build VM now has a 1 TB root volume (about 750 GB free at the start of the day), which was the
blocker for these two sets.

## SPL drug labels (openFDA drug/label) -> fda-drug-biologic-kg
- L0: 14 partitions, 1.8 GB zipped, export date 2026-10-27, 262,902 records, SHA-256 manifest.
- L1: `ex:DrugLabel` keyed by set id (`label/<set_id>`), every label section kept as text (tables
  included), `ex:effectiveTime` typed, links to substances (UNII), applications and package NDCs
  from the openfda block. 262,902 labels, 525,804 nodes, **10,232,798 triples**, written gzipped
  (1.97 GB). riot validates; chunked SHACL conforms after one shape change: openFDA spells five set
  ids in both letter cases, so those nodes carry two `ex:setId` spellings and the shape now says
  `minCount 1` only.

## FAERS (openFDA drug/event) -> fda-drug-event-kg (its own graph)
- L0: 1,767 partitions, 105 GB zipped, export date 2026-10-26, 20,692,690 reports. The fetcher
  makes up to six passes over missing partitions and writes the manifest only when every partition
  is on disk (transient DNS failures on the VM made that necessary); pass 1 completed with 0 missing.
- L1 is running in publish mode: `ex:AdverseEventReport` keyed by safetyreportid, patient, drug and
  reaction child nodes, MedDRA preferred-term text stripped (`reactionmeddrapt`; version numbers
  and outcome codes kept), report-level `ex:hasSubstance` and `ex:hasApplication` links lifted from
  the drug entries' openfda blocks. Own graph because PR #541 already told RENCI FAERS can be a
  separate repo. Counts go in the next change log.

## VAERS: blocked
The VAERS data downloads at vaers.hhs.gov sit behind a CAPTCHA, which the pipeline does not and
will not bypass. Roche downloads `AllVAERSDataCSVS.zip` by hand and places it in the project folder;
it then goes to the VM as a dated L0 snapshot and gets a converter (same strip-on-publish rule for
MedDRA symptom terms).

## Pipeline changes
- `fda_iri.py`: graph `fda-drug-event-kg`, minters `drug_label(set_id)`, `drug_event_report(id)`.
- `l1_openfda_any.py`: endpoints `drug/label` and `drug/event`, `_strip` walks nested paths,
  `_faers_links`.
- `gen_shapes.py`: `DrugLabel`, `AdverseEventReport`, `FaersReaction` (forbids `reactionmeddrapt`).
- `scripts/fetch_l0_phase3.sh`, `build_phase3.sh`, `run_phase3.sh`, `recheck_label_shacl.sh`.
