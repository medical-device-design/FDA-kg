# Change log, 2026-10-13: all six graphs built at L1

## Decisions (Roche)
- Build and complete all planned FDA graphs, not only Phase 1.
- Disk: regenerable outputs may be deleted when the VM fills, after asking. `animal_event.ttl`
  (9.4 GB) was deleted with approval and rebuilt gzipped.
- Licensed terminology: the VM copy keeps every field. `l1_openfda_any.py --publish` removes
  MedDRA reaction text (CAERS, cosmetic events) and VeDDRA term names (animal events, codes kept)
  until the licence decision in the handoff section 3.

## New code
- `pipeline/mapper.py`: the generic record-to-Turtle mapper shared by every converter
  (nested objects become child nodes, typed literals, five date shapes, child-IRI hook).
- `pipeline/l1_openfda_any.py`: one streaming converter for any openFDA endpoint, driven by the
  ENDPOINTS config table (15 endpoints so far). Writes `.ttl.gz` when asked.
- `pipeline/l1_tables.py`: Drugs@FDA data files (12 tables), Orange Book files (3), Purple Book
  monthly CSVs (80) and the fda.gov warning-letter index.
- `pipeline/fda_iri.py`: application, product, submission, NDC product and package, CAERS,
  cosmetic, animal event, tobacco and hashed-record minters. `normalize_application()` maps
  every spelling (NDA021234, "NDA 21234/S-012", "BL 125522", Orange Book "020512" + type A/N)
  to one IRI.
