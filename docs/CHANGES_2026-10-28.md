# Change log, 2026-10-28: FDA Data Dashboard (OII API), shared-VM conventions

## FDA Data Dashboard -> fda-compliance-kg (`fetch_l0_datadashboard.py`, `l1_datadashboard.py`)
The OII API key arrived (account approved for the Data Dashboard API and the Product Code Builder
API). The key lives in `~roche/.oii.env` on the VM (mode 600), read into request headers only.

- L0: four endpoints pulled in calendar-year windows, 5,000 rows per page, each window checked
  against the server's `totalrecordcount`: inspections_classifications 344,801 (2008 to 2026),
  inspections_citations 282,639, compliance_actions 178,208, import_refusals 211,920 (the API
  holds refusals from 2016 on). 656 MB of JSON, MANIFEST.json, SHA256SUMS.
- L1: `ex:InspectionClassification` 344,801 (223,242 NAI, 108,233 VAI, 13,326 OAI),
  `ex:InspectionCitation` 282,639, `ex:ComplianceAction` 178,208 (177,882 warning letters,
  244 injunctions, 82 seizures), `ex:ImportRefusal` 211,920, plus 277,629 `ex:Inspection` hub
  nodes and 308,281 `ex:Firm` nodes keyed by FEI (`firm/<FEI>`, name and address as last
  published). **33,213,642 triples**, riot validates, 9 SHACL chunks conform.
- The `firm/<FEI>` IRI is the one the DECRS, eBER and eHCTERS establishment records already
  point at with `ex:hasFirm`, so registrations, inspections, citations, actions and refusals
  now join on one node. Earlier those firm IRIs were undeclared stubs.
- Caught in review: `CitationID` is the citation type (the CFR section), not a row key; a first
  build keyed on it collapsed 282,639 rows to 4,324. Rows are now keyed by content.
- CLIIL (discontinued February 5, 2024) is covered by inspections_classifications.
